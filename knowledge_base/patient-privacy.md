Appointment details, contact numbers, and visit notes are visible only to staff assigned to that record. The support agent must not disclose one patient's information while helping a different patient. A record id is the lookup key so a visit can be discussed without repeating a patient's name in a shared channel. Every example used by this knowledge base is fabricated and is not a real medical record.
